# Student Performance Prediction



## Overview



This project investigates how students' lifestyle habits, academic behavior, and personal characteristics influence exam performance. Using exploratory data analysis, data preprocessing techniques, machine learning models, and dimensionality reduction methods, the project aims to classify student performance levels and identify the most influential factors affecting academic success.



The study combines statistical analysis and machine learning to provide insights that could help educators, institutions, and students better understand the drivers of academic achievement.



---



## Problem Statement



Student performance is influenced by multiple factors, including study habits, attendance, sleep patterns, social media usage, mental health, and family background. The goal of this project is to build predictive models capable of classifying students into different performance categories and to identify the variables that contribute most to academic outcomes.



---



## Dataset



The dataset contains information about student demographics, lifestyle habits, academic behavior, and exam scores.



### Features Include:



* Age

* Gender

* Study hours per day

* Social media usage

* Netflix usage

* Attendance percentage

* Sleep hours

* Exercise frequency

* Mental health rating

* Parental education level

* Diet quality

* Internet quality

* Extracurricular participation

* Part-time job status



### Target Variable



* Student Exam Performance Category



---



## Project Workflow



### 1. Exploratory Data Analysis (EDA)



* Descriptive statistics

* Distribution analysis

* Histograms and visualizations

* Correlation analysis

* Numerical vs categorical feature analysis

* Outlier investigation



### 2. Data Preprocessing



* Missing value handling

* Duplicate checking

* Categorical feature encoding

* Feature scaling

* Feature engineering

* Class imbalance treatment using SMOTE



### 3. Dimensionality Reduction



* Principal Component Analysis (PCA)

* Variance explained analysis



### 4. Unsupervised Learning



* Exploratory clustering analysis

* Pattern discovery among student groups



### 5. Supervised Machine Learning



The following models were developed and evaluated:



* Random Forest Classifier

* Logistic Regression



### 6. Hyperparameter Optimization



* Grid Search

* K-Fold Cross Validation



### 7. Model Evaluation



Performance was assessed using:



* Accuracy

* Precision

* Recall

* F1 Score

* Confusion Matrix

* Cross-validation metrics
